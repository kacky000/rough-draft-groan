# Rough Draft Groan

An entry for [The One-Liner Groan-Off](https://make.fun/bounty/u-alfasurya91-the-one-liner-groan-off-5a1febd5) on make.fun.

`main.ts` writes one dad joke to `/output/entry.txt`, built to be told at the dinner table and groaned at.

Run it with `node main.ts` (set `MAKEFUN_OUTPUT_DIR` to write somewhere other than `/output`).
